
# Mail Script

A Bash script that sends an email to regular user accounts on a Linux system using a `for` loop.

## Files

- `mymail.sh`: Sends the email to the selected user accounts.
- `mtemplate`: Contains the email message body.

## Usage

Run the script from the directory containing both files:

```bash
bash mymail.sh
```

## Requirements

- Linux
- Bash
- `mail` command
- A configured mail delivery service
