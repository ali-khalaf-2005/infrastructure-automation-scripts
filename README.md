# Infrastructure Automation Scripts

Bash and Python scripts for automating common Linux administration tasks.

This repository is a collection of practical scripts for system maintenance, backups, monitoring, and other repetitive tasks.

## Repository Structure

```text
infrastructure-automation-scripts/
├── bash-lab/
├── bash-scripts/
├── .gitignore
├── LICENSE
└── README.md
```

### Directories

- **`bash-lab/`** — Small scripts for individual Linux administration tasks.
- **`bash-scripts/`** — Scripts for more complete automation tasks.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ali-khalaf-2005/infrastructure-automation-scripts.git
cd infrastructure-automation-scripts
```

Open the directory containing the script you want to use. Check its contents and any requirements before running it.

For a Bash script:

```bash
chmod +x script-name.sh
./script-name.sh
```

You can also run it with Bash directly:

```bash
bash script-name.sh
```

Replace `script-name.sh` with the actual script filename.

## Requirements

- Linux or a compatible Bash environment
- Bash
- Any additional tools required by a specific script

Some scripts may require elevated permissions. Use `sudo` only when necessary.

## Notes

Scripts are developed and tested individually. Review each script before running it, especially when using it on a system containing important data.
