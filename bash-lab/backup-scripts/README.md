# Bash Backup Script

A simple Bash script that copies regular files from the home directory to a backup directory.

## Features
- Creates the backup directory if it does not exist.
- Copies regular files from the home directory.
- Skips directories and other non-regular files.
- Displays a completion message.

## Usage

```bash
bash backup.sh
```

## Backup Location

```text
~/backup/
```

## Requirements
- Linux
- Bash
